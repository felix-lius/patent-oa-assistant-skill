# 发明专利OA助手（invention-patent-oa-assistant）

> 针对中国发明专利申请的审查意见通知书（OA）提供不中断全自动答复支持的 AI skill 交付包。

## 一、这是什么

针对中国**发明专利申请**的**审查意见通知书（OA）**提供**不中断的全自动答复支持**的 AI skill。重点覆盖创造性审查意见（专利法第22条第3款），同时扫描常规条款缺陷防止遗漏、识别程序性要素（分案/优先权/同日申请）。从材料收集到《意见陈述书》初稿一次性生成，全程不中断、零第三方依赖。**适用范围：仅限发明专利申请的审查阶段答复，不适用于实用新型；生物材料保藏、遗传资源、保密审查等条款不属扫描对象（见速查表第十二节）。**

## 二、怎么用

在对话中发送以下任一触发语，并附上必需材料：

- "帮我答复这个审查意见"
- "分析一下这份OA"
- "这个驳回条款怎么争辩"
- "帮我写意见陈述书"
- "帮我修改权利要求答复审查意见"

**必需材料（缺一即停止，会提示补齐）**：
1. 审查意见通知书全文
2. 申请文件：权利要求书 + 说明书 + 附图
3. 审查员引用的对比文件全文

## 四、核心规则速览

| 规则 | 说明 |
|---|---|
| 材料完备性 | 通知书/申请文件/对比文件缺一 → **停止**，输出缺口清单，不硬生成 |
| 不中断 | 材料齐备后 11 步自动流转，一次交付完整初稿 |
| 引用铁律 | 区别特征逐字引用原文 + 附图标记，禁止概括改写 |
| 真实性 | 不编造对比文件内容/段落号/法条原文/实施例数据 |
| 条号 | 专利法 2020 / 实施细则 2023 / 审查指南 2023（现行版） |
| docx 生成 | 脚本纯 Python 标准库实现，零第三方依赖（可选使用） |

## 五、免责声明

- 本技能输出为**分析辅助与初稿**，不构成法律意见；正式提交前须由执业代理人复核技术事实、法条引用、修改文本与答复策略。
- 法条以现行有效版本为准（专利法 2020 修正、实施细则 2023 修订、审查指南 2023）；引用前请核取官方文本。
- 本技能仅适用于中国发明专利申请的审查阶段答复，不适用于实用新型、复审、无效宣告、PCT 国际阶段等程序。
