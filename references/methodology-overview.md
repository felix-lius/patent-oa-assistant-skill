# 答复方法论速览（methodology-overview）

> **用途**：一页纸总览专利OA答复的核心方法论，供代理人快速复核 skill 的分析逻辑，也可作为 AI 执行时的快速导航（细节以 `inventive-step-analysis.md` 等文件为准）。

---

## 一、三步法（创造性判断主线，审查指南第二部分第四章）

```
第一步：确定最接近的现有技术（D1 选择检验：技术领域/技术问题/方案接近度/效果对应）
第二步：确定区别特征 + 实际解决的技术问题（技术问题不得含特征指引）
第三步：判断是否显而易见（是否存在技术启示）
```

我方答辩 = 用三步法重走审查员路径，逐环节找漏洞。

## 二、双向核查（区别特征的"安检"）

| 核查 | 方向 | 防什么 | 结论类型 |
|---|---|---|---|
| 特征对应关系核查 | 审查员说"公开了" → 核查是否真公开 | 防审查员**过度认定** | 真实对应/名称相同实质不同/对应错位/上位对下位/割裂拼凑 |
| 区别特征自证核查 | 我方说"没公开" → 核查是否真没公开 | 防我方**过度主张**（自曝其短） | 确未公开/自查发现被公开（不主张）/无法核实（停止） |

## 三、授权前景客观评估（四维评分，共 20 分）

| 维度 | 要点 | 高分 | 低分 |
|---|---|---|---|
| 区别特征强度 | 是否有独立于对比文件的实质差异 | 核心结构/功能差异 | 近等同替换 |
| 对比文件接近程度 | D1 共有特征、D2 结合启示 | 领域远、结合需大改 | 高度接近、启示强 |
| 修改空间 | 可并入强特征数量、超范围风险 | 多且出处明确 | 无或存疑 |
| 争辩空间 | 结合能否阻断、公知常识有无举证 | D2 有自身缺陷 | 结合顺理成章 |

- 🟢 ≥16：纯争辩或最小必要修改 ｜ 🟡 10-15：最小必要修改+强争辩 ｜ 🔴 <10：才考虑全部并入
- **审查员第 7 项"无授权前景"不作决策标准**（常规施压表述），仅作预期反应参考。

## 四、合并范围决策（防过度限缩）

- **默认最小必要修改**：只并入克服创造性所必需的强区别特征，其余保留为从权；
- 范围**不可逆**（答复后不能扩大），宁可少并、留出渐进限缩空间；
- "全部并入"仅在客观评估🔴弱时作为**备选策略**呈现（是否采用由申请人/代理人提交前决定）；
- 修改对照页标注"未并入特征及理由"。

## 五、结合启示阻断（多篇对比文件组合否定时的核心武器）

1. **目的性驱动缺失**：D2 特征是为解决 D2 自身问题而设，移植到 D1 缺动机；
2. **物理 / 逻辑冲突**：强行应用是否破坏 D1 功能 / 打破平衡 / 使目的落空（按 7.3 改动量清点展开：依赖 → 接口 → 连锁 → 定性）；
3. **功能实现检验**：移入后该特征**自身**还能否实现其在 D2 中的功能（失效 / 退化 / 沦为冗余即无迁移动机）——**力度强于第 2 层**：第 2 层可被"牺牲部分性能可以接受"化解，第 3 层无从化解；
4. **教导缺失**：公开 ≠ 教导，D2 未给出结合方法。

补充武器：改动量清点（对抗"适应性调整 / 简单替换"断言，见 7.3）、相反教导三步法（见 7.2，零外部依赖）、核心枢纽不可替换（替换则全部效果落空）。

## 五之二、程序性要素识别（Step 2）

| 要素 | 影响 |
|---|---|
| 分案申请 | A33 超范围判断以**母案原始记载**为基准 |
| 要求优先权 | 现有技术时间点以优先权日为准（优先权成立时） |
| 同日申请 | 涉 A9.1 时答复须处理放弃声明或修改方案 |
| 无法确定 | 列入《附件·答复辅助材料汇总·提交前复核清单》，不臆断 |

## 六、关键纪律（红线）

| 纪律 | 内容 |
|---|---|
| 材料完备性 | 通知书/申请文件/对比文件/（二次OA的上次答复）缺一 → 停止，不硬生成 |
| 引用铁律 | 区别特征逐字引用原文+附图标记，禁止概括改写 |
| 真实性 | 不编造对比文件内容/段落号/法条原文/实施例数据 |
| 风格 | 全角标点、无AI痕迹、无框架术语泄漏、语气克制 |
| 条号 | 专利法2020/细则2023/审查指南2023，旧条号当场纠正（R20.2→R23.2、A59.1→A64.1） |
| 范围 | **仅限发明专利**（创造性标准：突出的实质性特点和显著的进步） |

## 七、策略双轨呈现（推荐 + 备选，决策权归用户）

| 轨 | 内容 | 范围影响 |
|---|---|---|
| 推荐策略 | 按授权前景基调选出（🟢纯争辩或最小必要 / 🟡最小必要+强争辩 / 🔴更大并入为主） | 按基调 |
| 备选1 纯争辩不修改 | 特征留原权利要求 | 保护范围不变 |
| 备选2 更大并入保授权 | 并入更多/全部强区别特征 | 大幅限缩（需申请人确认） |

- **论证素材与策略解耦**：逐特征论证为共享素材库，切换策略仅重排并入/留从权分配，无需重跑全流程；
- 评分（20 分制）为内部指引，交付物只呈现定性结论（强/中/弱）+ 理由。
