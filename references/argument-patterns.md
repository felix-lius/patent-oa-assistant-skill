# 高价值论证模式库（argument-patterns）

> **用途**：Step 7 逐特征深度论证时按需选用。以下为创造性答复中经实务验证有效的通用论证手法，每个模式给出适用场景、论证要点与句式参考。**同一案件按需选用 3-5 个（模式库现含 11 个，覆盖常见认定类型），避免全部堆砌导致篇幅失控；不同特征避免复用同一模式；可组合使用（如模式 2+9、4+11），组合时注意句式差异化。**
>
> **版权注意**：本文件为方法论提炼（行业通用论证逻辑），非任何第三方文本的复制；使用时仍须以案件具体技术事实为准。

---

## 模式 1：核心枢纽不可替换论证

**适用场景**：审查员认定将最接近现有技术（D1）的核心部件替换为常规设备/常规结构属"等同替换""常规选择"。

**论证要点**：
- 指出被替换部件在 D1 中承担**多重串联功能**（一项主功能之外还驱动其余部件联动），是 D1 的动力/功能枢纽；
- 推演替换后果：被替换后 D1 其余联动部件全部失去动力/失效，**全部有益效果同时落空**；
- 结论：以牺牲被改造方案核心有益效果为代价的替换，本领域技术人员无动机实施，也不构成显而易见的改进；
- 若审查员给出的替换动机（如"减少某风险"）在 D1 中并无事实基础，一并指出。

**句式参考**："更为根本的是，××部件在对比文件×中承担着唯一动力枢纽的角色……若按照审查意见的认定将其替换为××，××将随之失去动力，××体系将全部失效，对比文件×的全部有益效果将同时落空。以牺牲被改造方案核心有益效果为代价的替换，本领域技术人员既无动机实施，也不构成显而易见的改进。"

## 模式 2：移用技术障碍论证（结合启示的硬核反驳）

**适用场景**：审查员认为其他对比文件（D2）的某特征可替换 D1 对应特征，且称"结构细节可适应性调整"。

**论证要点**：
- D2 特征正常工作依赖其**配套装置持续约束**（如轨道沿输送路径全程布置、外部支撑结构）；
- 检查 D1 对应区域**是否具备增设该配套装置的安装空间与结构接口**——通常没有；
- 结论：将 D2 的特征连同配套装置整体移入 D1，需对 D1 的整体结构近乎推倒重来，已超越"简单替换/适应性调整"范畴，本领域技术人员不会仅因知晓 D2 就产生如此大规模的改造动机。

**句式参考**："退一步而言，即便本领域技术人员试图将对比文件×的××及配套装置整体移用于对比文件×，仍存在难以逾越的结构障碍。对比文件×的××依靠××持续约束来维持其功能，而对比文件×中××周围并未设置也不具备增设××的安装空间与结构接口。将××整体移入，需要对对比文件×进行近乎推倒重来的改造，已超出'简单替换'范畴。"

## 模式 3：一形两用几何论证

**适用场景**：审查员将功能复合构件（同一构件分时承担两种功能）的结构差异认定为"具体结构及连接细节的适应性调整"。

**论证要点**：
- 明确该构件两种状态下的**几何功能要求**（如张开态贴合刮取、闭合态靠拢夹持）；
- 指出两种功能对该构件的空间位置与几何外形提出不同要求（弧度、长度、张角范围需专门设计），即"一形两用"；
- 对比现有技术：D1 对应构件仅承担单一功能、D2 构件亦仅承担单一功能，均无"一形两用"教导；
- 结论：专门几何设计非"简单叠加"，亦非无需创造性劳动即可完成。

**句式参考**："还需要指出的是，本案××的几何设计满足了'一形两用'的要求：××处于××状态时，其外缘需要……；××处于××状态时，其内侧面需要……。两种功能对××的空间位置和几何外形提出了不同要求……对比文件×中的××仅设计为××面，只承担单一功能，二者均未给出同一构件分时兼具两种功能的几何设计教导。"

## 模式 4：核心构思统领协同论证

**适用场景**：整体效果/协同作用论述。

**论证要点**：
- 为整体方案提炼**凝练的核心构思表述**（如"刮夹同体、分时切换"），点明发明灵魂；
- 以核心构件为圆心，将各区别特征按"支撑核心循环"的角色逐一串接（谁提供基准、谁保证同步、谁触发时序、谁消除干扰）；
- 补一句回应"常规载体"认定："即使某部件本身常见，其在本方案中作为统一刚性安装基准、决定同步与时序精度的作用已超出常规范畴"；
- 结论：任一特征缺失则循环中断，整体效果远超简单叠加。

**注意**：协同论证控制在 600 字以内，确保审查员有耐心通读。

## 模式 5：预防性回应（预判驳回理由）

**适用场景**：答复阶段预判审查员可能在驳回决定中提出的反驳。

**论证要点**：
- 预判常见驳回理由：①构件本身是已知机构/原理；②状态选择属常规选择；
- 回应焦点转向**整体方案**：创造性判断对象不是构件本身，而是该构件与本案整体架构（一体化套装、同步传动、固定触发系统）相结合、在特定场景实现特定功能组合的整体技术方案；
- 句式宜用"我方理解××作为××原理并不鲜见，但创造性判断的对象是要求保护的技术方案整体……对比文件×均未给出将××用于××场景的任何教导"。

**注意**：预防性回应应适度（每处 1-2 句），避免过度防御显得心虚。

## 模式 6：技术问题不当指引争点

**适用场景**：审查员在第二步概括的"实际解决的技术问题"包含对区别技术特征本身的指引。

**论证要点**：
- 客观重新确定技术问题（基于区别特征达到的技术效果，不含解决方案指引）；
- 善意指出审查员概括含指引成分，与客观重新确定的要求不尽相符，恳请以客观表述重新确定；
- 放在第二步结尾，语气谦和："发明人特此说明，并恳请以客观表述重新确定实际解决的技术问题。"

## 模式 7：数值范围与参数限定的临界论证

**适用场景**：审查员将数值范围/参数限定（温度、压力、配比、尺寸、转速等）认定为"常规选择""通过有限试验即可确定"。

**论证要点**：
- 指出该数值范围并非在现有技术宽泛范围内任意选取，而是基于特定技术效果**反向推导确定的临界点**（如超过上限则结构失效/低于下限则功能缺失/临界值打破原有矛盾）；
- 核对审查员是否举证了现有技术中的具体数值教导——未举证的"常规选择"认定缺乏支撑；
- 若有实施例数据支撑，论证该范围的不可预期性（范围内效果稳定、范围外效果劣化或丧失）；
- 注意区分：数值范围本身来自说明书实施例的，须强调其与所要解决的技术问题的直接关联。

**句式参考**："该数值范围并非本领域技术人员在常规设计中选择的任意取值。本申请经试验发现，××低于×时××无法实现，高于×时××发生劣化，唯有在×至×的区间内方能同时满足××与××的要求。审查意见未指出现有技术中对上述范围的任何数值教导，亦未说明选择该范围所需的技术启示。"

## 模式 8：方法步骤时序与执行顺序论证

**适用场景**：审查员认定方法权利要求中各步骤的执行顺序/时序配合为"常规排序""步骤顺序的适应性调整"。

**论证要点**：
- 论证步骤间存在**逻辑依赖与时序约束**（后一步骤依赖前一步骤的输出/状态，顺序颠倒则方案无法实施或效果丧失）；
- 对比文件中对应步骤的关系（并列/独立/顺序可换）与本申请（强制串行/反馈闭环）的本质差异；
- 若存在循环/反馈/条件分支，强调其与线性流程的结构性区别，非简单排序问题。

**句式参考**："本申请方法步骤并非若干操作的简单排列：步骤×的执行结果构成步骤×的输入前提，二者之间存在严格的时序依赖……对比文件×中各步骤彼此独立、顺序可以互换，与本申请存在本质差异。"

## 模式 9：跨领域移植障碍论证

**适用场景**：审查员以另一技术领域（D2）的常规手段否定本申请特征，认为"将该领域的公知手段用于本申请领域是容易想到的"。

**论证要点**：
- 论证本申请领域与 D2 领域在技术规范、工作环境、性能指标上的系统性差异（如精度要求、工况条件、安全标准、成本约束）；
- 本领域技术人员长期在本领域既有框架内工作，缺乏跨领域借鉴的动机与认知（不同领域的技术人员群体、知识体系不同）；
- D2 中的手段移植到本领域需解决领域特有的适配问题，且该适配问题本身即非显而易见；
- 结合"移用技术障碍"模式 2 使用更佳。

**句式参考**："××手段虽在××领域有所应用，但本申请所处的××领域与其在技术要求上存在本质差异：××领域的××指标要求远高于该手段常规应用场景……本领域技术人员专注于本领域既有技术框架，并无将跨领域手段引入的明确动机，即便知晓该手段，亦不存在将其应用于本申请的启示。"

## 模式 10：技术偏见与行业固化思维破除论证

**适用场景**：审查员以"本领域技术人员不会考虑/常规做法是××"为由否定，或相反地认为某特征属于常规手段，而本申请恰恰打破行业普遍认知。

**论证要点**：
- 举证本领域普遍存在的技术偏见（行业标准做法、主流文献导向、教科书常规路径均避开本申请方案）；
- 论证本申请正是对该普遍认知的突破（反向设计/悖于常理的选择/解决被长期忽视的痛点）；
- 强调"普通技术人员被既有认知束缚"——若方案与其说符合常规不如说背离常规，则显然非显而易见；
- **注意**：此处反向证据方向与公知常识反击一致（见 inventive-step-analysis 类型三检索红线），只检索相反教导/技术偏见类文献，不检索教科书证明"无记载"。

**句式参考**："本领域长期以来的常规做法是××（参见……），以避免××风险。本申请反其道而行，通过××实现了……这一设计方向与本领域普遍认知相悖，普通技术人员受既有认知束缚，难以产生这样的改进思路。"

## 模式 11：预料不到的技术效果论证（有数据支撑时）

**适用场景**：审查员承认区别特征但否定效果显著性，或对效果与区别特征的因果关系提出质疑。

**论证要点**：
- 从说明书实施例数据出发，量化呈现效果（对比对比例/现有技术基线）；
- 建立**效果与区别特征之间的因果链**（特征→机制→效果），避免罗列数据无论证；
- 指出效果超出各特征简单叠加（协同），或达成现有技术长期追求而未达成的目标；
- 效果数据引用须忠实原文，无数据的标注按正文零标记纪律登记《附件·答复辅助材料汇总·待核实事项清单》。

**句式参考**："说明书实施例×至×的数据表明，采用××后××指标由×提升至×，提升幅度超出××单独作用之和……上述效果直接源于××特征带来的××机理变化，并非现有技术效果的简单累加。"

## 选用建议

| 审查员认定类型 | 优先选用的模式 |
|---|---|
| 常规等同替换 | 模式 1（核心枢纽）+ 模式 2（移用障碍） |
| 其他对比文件结合 | 模式 2（移用障碍）+ 结合启示阻断三层递进 |
| 适应性调整/结构细节 | 模式 3（一形两用）+ 模式 2 |
| 协同作用/整体效果 | 模式 4（核心构思统领） |
| 预判驳回 | 模式 5（预防性回应，放特征论证末尾） |
| 技术问题概括不当 | 模式 6（放第二步） |
| 数值范围/参数选择被否 | 模式 7（数值临界）+ 模式 11（效果数据） |
| 方法步骤顺序被否 | 模式 8（时序依赖） |
| 跨领域手段引入被否 | 模式 9（跨领域障碍）+ 模式 2 |
| 常规手段/公知常识认定 | 模式 10（技术偏见）+ 类型三四层论证 |
| 效果显著性被否 | 模式 11（预料不到效果）+ 模式 4 |

**使用纪律**：同一案件按需选用 3-5 个模式，避免堆砌；不同特征避免复用同一模式；模式 7-11 与模式 1-6 可组合（如 2+9、4+11），组合使用时注意句式差异化。
