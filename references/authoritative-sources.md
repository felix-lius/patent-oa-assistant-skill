# 外部参考与资源登记（authoritative-sources）

> **用途**：本文件登记 skill 的官方检索资源入口与排版规范。**不内嵌任何受版权保护的内容原文**；法条、审查指南引用一律以官方现行文本为准，按需联网核取，保证条号与内容长期准确。

---

## 一、法条与审查指南官方获取源（联网核取现行文本用）

| 资源 | 入口 | 用途 |
|---|---|---|
| 国家法律法规数据库 | flk.npc.gov.cn | 《专利法》《专利法实施细则》官方现行文本 |
| 国知局官网 | www.cnipa.gov.cn | 《专利审查指南》2023 官方发布版、审查指南修改公报 |
| 国家知识产权局专利业务办理系统 | 官方入口 | 通知书、审查文件官方来源 |

> 规则：法条原文引用前必须核取官方现行文本；条号以 2020 专利法 / 2023 细则为准。

## 二、对比文件全文获取

**获取优先级：先本地文件，再国内可访问源，最后境外源**。材料缺口时按此顺序尝试补齐，补齐失败即停止流程（见 SKILL.md Step 1 完备性检查）。

| 资源 | 入口 | 说明 | 国内可访问性 |
|---|---|---|---|
| 用户本地文件 | 用户提供的对比文件 PDF/文本 | 最可靠，优先使用 | ✅ |
| 掌桥科研 | `zhangqiaokeyan.com`（站内搜索公开号） | 提供著录项+摘要，部分全文；实测可访问 | ✅ 优先 |
| 天眼查专利 | `zhuanli.tianyancha.com`（搜索公开号） | 提供著录项+摘要+权利要求部分 | ✅ 优先 |
| CNIPA 专利检索及分析系统 | 国知局官方检索系统 | 对比文件全文官方来源 | ✅（需注册登录） |
| 万方专利 | `d.wanfangdata.com.cn` | 著录项+摘要 | ✅（部分需付费） |
| Google Patents | `https://patents.google.com/patent/<公开号>` | 免费公开全文；链接可由公开号可靠构造 | ⚠️ 国内网络通常不可用，作备选 |
| 其他境外库 | FreePatentsOnline / Espacenet | 备选来源 | ⚠️ 视网络环境 |

> 规则：**禁止编造 URL 与对比文件内容**。链接由公开号推导时先验证格式；全部来源均无法获取时，在《材料缺口清单》中给出指引并停止流程，不得以通知书转述内容替代对比文件原文继续生成初稿。

## 四、docx 输出排版规范参考（将来如需生成 Word 交付物）

若用户后续要求输出 .docx 格式，可按**行业通行格式**由 AI 直接生成或参考以下规范（国知局对意见陈述书无统一强制版式，此为实务通行标准）：

| 排版项 | 规范 |
|---|---|
| 字体 | 华文仿宋（回退仿宋） |
| 字号 | 正文小四（12pt）、一级标题三号（16pt）、二级标题四号（14pt） |
| 缩进 | 首行缩进 2 字符 |
| 编号体系 | 一、→（一）→ 1. →（1） |
| 行距 | 1.5 倍 |
| 内容约束 | 开头直接从"尊敬的审查员："开始；结尾无落款日期；区别特征段落标题加粗 |

> 注：此规范为行业通行格式（参考 `scripts/generate_docx.py` 的排版参数提炼），非版权内容；实际生成 docx 前需按用户环境确认字体可用性。

## 五、使用纪律

1. 本 skill 的一切结论以**用户提供的申请文件与通知书原文**为事实基础。
2. 法条、审查指南、对比文件内容引用一律注明来源并可追溯；无法核实的**不写入正文**（正文零标记残留），统一登记《附件·答复辅助材料汇总·待核实事项清单》。
3. 受版权材料只用于方法借鉴，绝不整段复制进交付物。
